# ADR 0004: In-Process First, Optional Server

- Status: Accepted
- Date: 2026-06-11

## Context

Shibahama is meant to be embedded by coding agents, local tools, notebooks, and agent frameworks.
The PRD frames it as infrastructure any host can use, not a standalone agent platform. A required
daemon would make first use heavier, complicate Python and Node package installation, and obscure the
core behavior behind network concerns too early.

At the same time, team and multi-agent deployments need a server mode for namespace isolation,
shared stores, observability, and auth.

## Decision

Build Shibahama as an in-process Rust core first. Python and Node bindings call the same core library
directly. The optional server mode is a thin wrapper around that core API, not a separate
implementation.

The small public API remains the source of truth across all surfaces:

- `write`
- `recall`
- `reinforce`
- `why`
- `timeline`

Server mode may add transport concerns such as authentication, quotas, namespaces, and health checks,
but it must not introduce semantics unavailable to embedded users.

## Rationale

In-process first makes local adoption low-friction and keeps latency predictable for agent loops.
It also forces the core API to be clean: if Python, Node, CLI, server, benchmarks, and Tideline all
share the same Rust behavior, inconsistencies are easier to detect.

Optional server mode is still important, but it should arrive after the core API and storage
semantics are tested. Server features are deployment policy, not the heart of the memory engine.

## Consequences

- Public behavior must live in `shibahama-core`, not in binding-specific glue or HTTP handlers.
- The core crate cannot assume a global singleton, process-wide runtime, or long-lived daemon.
- Server APIs must be contract-tested against the embedded core behavior.
- Bindings should expose local-store configuration before remote-client configuration.
- The Tideline can consume a server stream when available, but the event/state stream must be
  generated by the core.
