# Singapore boundary profile

The `sg` profile applies the common baseline plus Singapore strict terms and labelled UEN/IRAS/Myinfo patterns. It
routes NRIC/FIN/M-prefix identifiers, UENs, IRAS ASGD/ITR references, Myinfo identity-field markers, SFA section 218,
and inside-information terms for review. It is a lexical boundary profile, not a legal decision.

## Citation convention

Record the authority title, issuer, version/date, canonical official link, access date, and verification actor. For
legislation, use eGazette as the prescribed publication where applicable; Singapore Statutes Online is a useful
consolidated reference but not a substitute for the prescribed publication. See the canonical-source note.

## Known limits

The profile cannot establish PDPA compliance, privilege, client consent, overseas-transfer validity, professional
supervision, or whether information is legally inside information. Check current primary sources and firm controls.
