# Early User Outreach

Initial issue themes to collect from reviewers:

1. Dependency tagging ergonomics: how quickly can a curator add or confirm authority edges?
2. Staleness explanations: do lawyers understand "flag, don't adjudicate"?
3. Boundary confidence: what proof do reviewers need that client identity did not cross?
4. Report usefulness: does the matter/client currency report answer privilege-defence questions?

Use GitHub issues with labels `early-user`, `demo-feedback`, and `currency-report`.
