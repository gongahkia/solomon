# Shibahama Perf Benchmarks

Criterion harness for Phase A performance proof.

Run all item 22 benches:

```sh
cargo bench -p shibahama-perf
```

Build without running:

```sh
cargo bench -p shibahama-perf --no-run
```

Generate Phase A result artifacts for selected scale tiers:

```sh
cargo run -p shibahama-perf --release --bin record_perf -- \
  --tiers 1k,10k,100k \
  --queries 10 \
  --quality-tiers 10k,100k \
  --quality-queries 5 \
  --tier-breakdown \
  --tier-repetitions 3 \
  --output-dir benchmarks/results/perf \
  --omit-1m "1M local run omitted; immediate-durability ingest exceeded the available session budget" \
  --hnsw-m 8 \
  --hnsw-ef-construction 32 \
  --hnsw-ef-search 512
```

The default local smoke scale is 1,000 synthetic memories, 768-dimensional
unit-normalized embeddings, fixed seed `0x5f1ba4d020260001`, and `top_k = 10`.
The corpus is deterministic and generated by `src/harness.rs`.

Run the CI gross-regression smoke:

```sh
scripts/ci/perf-smoke.sh
```

It writes 1k artifacts to `target/perf-smoke` and fails when recall p99 exceeds
`SHIBAHAMA_PERF_SMOKE_P99_NS` (default `500000000` ns).
