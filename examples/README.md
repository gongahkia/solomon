# Examples

Runnable scenarios live here. The headline scenario is `stale-house-view`, which demonstrates a 2023
house-view memo becoming stale-pending-reverification after a 2025 dependency change.

`internal-supersession` demonstrates a 2024 position superseding a 2022 position on the same topic and
jurisdiction, with default recall hiding the superseded item and review mode preserving it for audit.
