# Internationalization

Shisa keeps translation catalogs under `i18n/` in gettext-compatible PO format.

Contribution steps live in [Translating Shisa](translating.md).

Regenerate the status table with:

```sh
scripts/i18n-status.sh
```

## Fixtures

RTL fixture strings live in `test/fixtures/i18n/rtl.json`. CJK width fixtures live in `test/fixtures/i18n/cjk.json`.

Shell init files provide locale-based BiDi direction detection by setting `SHISA_RTL` at session start from `LC_ALL`, then `LC_CTYPE`, then `LANG`. Arabic, Hebrew, Persian, Urdu, Pashto, Divehi, and Yiddish locales map to `SHISA_RTL=1`; explicit `SHISA_RTL` values are preserved.

Set `[prompt].rtl_reverse = true` to reverse rendered segment order only for sessions where `SHISA_RTL=1`.

Layout width uses Unicode 17.0 EastAsianWidth W/F ranges from UAX #11. Ambiguous-width characters remain one cell unless a later terminal-profile option changes that.
