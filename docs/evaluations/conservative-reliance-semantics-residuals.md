## Exact residual trace

The following source-level trace was generated by invoking the current citation and suggestion functions directly on
each reported fixture. Offsets below are raw character offsets in the fixture text.

| Fixture | Observable result | Verified local cause |
| --- | --- | --- |
| `adv-hold-03` | `Dune Act 5 section 11` was detected at `0:21`, but no suggestion was produced for “establishes the filing sequence used by …”. | The H2 `establishes` pattern accepts only `deadline`, `formula`, or `sequence` immediately after the verb. It does not allow the intervening noun `filing`. |
| `adv-hold-08` | `Cedar Code 9 section 3(b)` was detected at `34:59`, but no suggestion was produced for “required by … (notice to counterparty) before dispatch”. | The broad attributed-reliance guard treats the neutral parenthetical word `counterparty` as an attributed position and suppresses the otherwise direct `required by` relationship. |
| `adv-hold-13` | The first table reference was correct. The line-wrapped second reference became raw text `8\nCedar Code 9 section 3`, ID `8-cedar-code-9-section-3`, at `72:96`; `Boreal Rule 2 section 8` was omitted. | Citation-title recovery has no hard line-break boundary and relies on title capitalization. It incorrectly crosses a table row boundary. |
| `adv-hold-33` | The authority was parsed as `the Boreal Rule 2 section 8`, ID `the-boreal-rule-2-section-8`, at `19:46`; no suggestion was produced. | The title-start rule does not exclude the lowercase article `the`, so the registered authority ID cannot match. |
| `adv-hold-39` | Both citations were correct, but “replaces Boreal … with Cedar … for notice timing” created no suggestion. | No bounded replacement/reliance construction exists in the current H2 grammar. |
| `adv-hold-42` | The citation was correct, but “follows Boreal Rule 2 section 8 only if …” created no suggestion. | The H2 `follows` construction requires `for`; it does not recognize the qualified direct-reliance form. |
| `mut-01` | Base target was `aster-regulation-7-section-4`; its expanded-whitespace variant had no suggestion. | The direct cue is a literal `relies on` substring and cannot span normalized horizontal whitespace. Citation parsing and authority fingerprinting remained correct. |
| `mut-08` | Base target was `aster-regulation-7-section-4`; the case-mutated variant suggested only `regulation-7-section-4`. | The all-case variation breaks the uppercase-first-character title heuristic; `aSTER` is no longer included in the authority title. |

No other holdout fixture produced a suggestion error in this reproduction. The three reported reference errors are
`adv-hold-13` (two malformed/omitted table references) and `adv-hold-33` (one leading-article fingerprint). The four
reported reliance-cue errors are `adv-hold-03`, `adv-hold-08`, `adv-hold-39`, and `adv-hold-42`.

locally guarded reliance grammar. This report does not authorize a third parser strategy, a fallback classifier, an
automatic edge, a broader review queue, or a relaxation of any prior abstention/safety gate. The protocol and a new
