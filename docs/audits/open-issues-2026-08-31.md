## Historical versus current reconciliation

The tracker contains commit-level completion claims made when coverage was broader than the current test reality. The audit did not rely on those claims alone. The main material contradiction was the nominal PostgreSQL backend coverage: fake-backend tests failed before exercising the valid `pgvector` migration because the test adapter lacked a PostgreSQL-only `ALTER COLUMN SET NOT NULL` transition. The production migration remains transactional and was exercised against a real disposable PostgreSQL 16/pgvector instance. OIDC test collection also made one `nbf` case time-sensitive; the test now creates its invalid timestamp when invoked.

No new GitHub issue is required by this audit. The remaining pilot, registry, hosted CI, Pages, Codespaces, and native-macOS concerns are either external prerequisites or already bounded in the pilot plan and release gate. Creating duplicate tracker work would obscure the verified implementation state.
