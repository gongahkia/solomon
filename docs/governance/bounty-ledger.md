# Bounty Ledger

The security bounty pool is tracked through Open Collective:

- public page: https://opencollective.com/shisa
- machine-readable balance: https://opencollective.com/shisa.json
- restricted-fund label: `sandbox-bounty`

Only funds explicitly labeled `sandbox-bounty` count toward bounty awards. General project funds remain outside the pool until a public spending summary transfers them into the restricted bounty balance.

Before triaging a payable report, maintainers must record the current Open Collective balance, restricted bounty balance, pending awards, and remaining available pool in the private report notes. After disclosure, publish an anonymized summary with the award class and amount.
