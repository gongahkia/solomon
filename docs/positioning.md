# Positioning

The currency report is the visible output that makes Solomon legible to a non-technical buyer: it turns the currency engine from "search with a freshness tag" into an accountable partner artifact showing which firm positions went stale, contradictory, superseded, or retired in a period, which authority or dependency moved, and what verification status each position has now.
