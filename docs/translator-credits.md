# Translator Credits

Translator credit is opt-in.

No community translator credits are recorded yet.

## Entry Format

Add one line per credited translator:

```text
- Name or handle - locale(s), first credited version
```

Use the name, handle, and link the translator explicitly approved. Do not add private email addresses, payment details, or review-only contributors without consent.

## Review

Translation pull requests that add or change credits must include:

- locale
- approved display name or handle
- whether a homepage/profile link is approved
- validation command from [Translating Shisa](translating.md)
