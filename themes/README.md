# Built-in Themes

Built-ins:

- `plain`
- `minimal-monochrome`
- `okiya-night`
- `nord-dark`
- `gruvbox-rainbow`
- `tokyo-night`
- `pure`
- `a11y`

These files follow `docs/theme-spec.md` and are intended to be copied as starter external themes.

CI runs `scripts/theme-preview-screenshots.sh` and uploads SVG previews from `zig-out/theme-previews`.
