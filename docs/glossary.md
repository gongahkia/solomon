# Glossary

| Term | Meaning in Solomon |
| --- | --- |
| **Live** | Eligible for default recall because no stale, supersession, retirement, or blocking review signal applies. |
| **Stale-pending-reverification** | A dependency move, contest, or other currency signal requires human review before normal reuse. It does not mean the legal position is false. |
| **Superseded** | Preserved historical position replaced by a recorded successor. It remains available to review and historical queries. |
| **Retired** | Position intentionally taken out of normal use without deletion. |
| **Pinned** | Position with a firm-authoritative credence floor set by an authorised actor; lower-tier content cannot silently displace it. |
| **Credence tier** | Source-strength classification used to prevent weaker or model-inferred material from outranking firm-authoritative knowledge. |
| **Valid time** | Time during which a knowledge item or edge is asserted to have applied in the represented world. |
| **Ingestion time** | Time at which Solomon recorded the item or event. |
| **Boundary review** | Fail-closed inspection and policy decision before storing or exposing model-bound content. |
| **Audit pack** | Metadata-only export binding provenance, currency, verification, boundary, plan, and hash-chain evidence for review. |
| **Preflight context** | Scoped, current context returned to an MCP host before it assembles a prompt or work item. |
| **Dependency edge** | Directed relation showing that one knowledge item relies on another item or external authority. |
| **Contest** | Recorded challenge to a position that preserves the challenge and routes the position to review. |
| **Currency** | Deterministic assessment of whether a position is currently eligible for reuse and the evidence for that assessment. |
