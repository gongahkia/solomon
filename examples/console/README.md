# Console examples

Run the curator console against a local store:

```bash
uv run solomon console serve --host 127.0.0.1 --port 8150
```

Open `http://127.0.0.1:8150/console`.

For the static demo media, see [`docs/assets/console/`](../../docs/assets/console/).
