# Funding

Shisa funding is tracked through the public Open Collective ledger at https://opencollective.com/shisa and published GitHub Sponsors payout summaries. Funds are used for project maintenance costs only:

- sandbox escape bounty pool
- release infrastructure
- security review and accessibility audit costs
- documentation hosting
- community event materials
- contributor support for scoped maintenance work

Funding does not buy roadmap priority, maintainer access, feature commitments, or security exceptions. Sponsor recognition must stay separate from technical decision-making.

Maintainers should publish material spending summaries before accepting recurring community funds. Bounty-specific funds stay reserved for [Bug Bounty](docs/governance/bug-bounty.md) awards and direct award costs, with tracking rules in [Bounty Ledger](docs/governance/bounty-ledger.md). GitHub Sponsors receipts count toward the bounty pool only after a published `sandbox-bounty` ledger entry. Recognition rules live in [Sponsor Recognition](docs/governance/sponsor-recognition.md).
